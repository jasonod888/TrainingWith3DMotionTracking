# Synthetic symbolic music corpus

These authored expected-note sequences cover a scale, repeated attacks, a chord, an
optional teaching note, open guitar strings and silence. Proposal files intentionally
include one missing-note and one extra-note case. The index records expected counts.

No third-party recordings, performances, checkpoints or model output are included.
Review metadata is explicitly a **synthetic fixture author**, not an instructor's
approval of a real recording. These fixtures must not be presented as production lessons
or evidence of model accuracy, audio quality, onset alignment or hardware compatibility.

Regenerate deterministically with `python scripts/generate_music_corpus.py`.
Real acoustic qualification still needs rights-cleared recordings and instructor-reviewed
ground truth with representative instruments and recording conditions.
